# Rewsty Jinja Ninja

This repository provides setup instructions for integrating Rewsty Jinja Ninja with various AI models. Follow the steps below to prepare your environment and configure your preferred model.

## Features
- Step-by-step guides for setting up Rewsty Jinja Ninja
- Instructions for document grounding to ensure model accuracy
- Support for multiple platforms: Open WebUI, Google Gemini, Mistral LeChat, Github Copilot, Microsoft 365 Copilot

## Document Grounding
Before configuring your model, you need to obtain the most up-to-date documentation for grounding.

1. Go to [Use Gitingest](https://gitingest.com/).
2. Enter the following URL: `https://github.com/RewstApp/docs.rewst.help/tree/main/documentation/jinja`.
3. Download the generated text file. This file will be used to upload to your model of choice's knowledge base.
