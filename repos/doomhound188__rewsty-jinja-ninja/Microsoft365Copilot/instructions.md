# Microsoft 365 Copilot Setup

1. Launch the Microsoft 365 Copilot App, log into the app if not already logged in.
2. Click "Create Agent" in the left pane menu.
3. Click "Configure" in the new Agent setup window.
4. Fill in the Name, Description and paste the contents of `message.txt` in the Instructions field.
5. In the Knowledge section, you can either:
    - Add the Jinja docs URL: `https://github.com/RewstApp/docs.rewst.help/tree/main/documentation/jinja`
    - OR upload the jinja document retrieved from [Gitingest](https://gitingest.com/) using the above URL.
6. Once all settings are set as desired click "Create" in the top right corner and test your newly published model.
