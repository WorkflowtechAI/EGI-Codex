log into Mistral https://chat.mistral.ai/

select Agents -> Create an Agent

Paste message.txt contents into Instructions

click Knowledge and Create a library

on the Libraries screen click New Library

upload the text file generated from [Gitingest](https://gitingest.com/) (using `https://github.com/RewstApp/docs.rewst.help/tree/main/documentation/jinja`) and give the library a name

go back to your Agent 

tick the radial button to add the rewstapp-docs to your agent

test the agent 

You have successfully completed the Mistral Setup
