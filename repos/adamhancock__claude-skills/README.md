# Claude Skills

A collection of skills for [Claude Code](https://docs.anthropic.com/en/docs/claude-code).

## Skills

### Rewst

Comprehensive skill for the [Rewst](https://rewst.io) automation platform - building workflows, writing Jinja templates, designing automations, and referencing Rewst-specific syntax.

**Install:**

```bash
claude install-skill https://github.com/adamhancock/claude-skills/tree/main/skills/rewst
```
