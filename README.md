# EGI Automation Codex

A curated catalog of community-built automation content, pulled from public sources (GitHub, Reddit, blog posts, practitioner interviews) and organized for use by Eudai Gestalt Integrations (EGI) and its clients.

## What's in here

- `INDEX.md` is the master catalog. Start here. Lists every tracked repo, contributor, and reference document with one-line context.
- `repos/` holds snapshots of third-party Rewst-related repositories. Each subdirectory preserves the original LICENSE and authorship. See `NOTICE` for licensing scope.
- `contributors/` holds profiles of Rewst community practitioners whose public work is catalogued here.
- `reference/` holds background material: the Workflow Wizards series, the Rewst January 2026 layoffs context, Reddit author tracking, the GigaCode blog, and similar.
- `blog-posts/` holds captures of practitioner blog posts that risk going offline.
- `discord-exports/` holds manual exports from the Rewst community Discord when the original author authorizes it.
- `dashboards/`, `scripts/`, `workflows/` hold EGI-authored tooling that supports the catalog or ships as reusable Rewst assets.

## How to use it

Browse `INDEX.md` for the full catalog with commentary. Each repo has a tier designation and a one-line reason it is catalogued. Every snapshot under `repos/` is a standard directory tree you can copy into your own workspace or extract specific files from.

## Scope and methodology

Only public content is catalogued. Nothing from private repos, Discord mod-only channels, or internal Rewst materials. Each snapshot records the upstream URL and the pull date. Content pulled is not modified. If EGI annotates a snapshot, the annotation lives in a sibling `EGI-NOTES.md` file alongside the snapshot, not inside it.

The catalog is not exhaustive. It reflects what EGI uses in practice and what EGI has assessed as reusable by the broader Rewst community.

## Attribution and removal requests

If you authored a repo snapshotted here and want it removed, re-attributed, or updated to a newer version, open an issue on this repository or contact EGI directly. The `NOTICE` file spells out the licensing boundary between EGI-authored prose and third-party snapshots.
