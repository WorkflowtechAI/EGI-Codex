# John Duprey

**GitHub:** <https://github.com/JohnDuprey>

## Why he matters to EGI

John's repo is the most visible bridge between Rewst and CIPP (the open-source M365 automation suite by Kelvin Tegelaar). Any EGI client running both will eventually need this interop layer, and John's bundles are the baseline.

## Published content

### `JohnDuprey/RewstWorkflows` (8 stars, active 2026)

Each subdirectory has its own README.

- **CIPP-User-Invite** — invite a user via CIPP from a Rewst trigger. Useful as part of onboarding flows where CIPP does the M365 provisioning and Rewst orchestrates.
- **CIPP-Repository-Diagnostic** — diagnostic workflow against a CIPP deployment. Probably checks reachability, auth, endpoint health. Worth reading as a reference for how to health-check an external tool from Rewst.
- **Meme-Generator** — returns a generated meme. Lightweight, but useful in Teams-bot contexts as a working example of a non-business workflow.
